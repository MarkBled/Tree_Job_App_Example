3 · What Z3’s result actually proves

  • For every atom and node (each candidate, each mode) Z3 decided whether facts ∧ ¬φ or facts ∧ φ is unsatisfiable. For every UNSAT answer it returned a core that was shrunk one by one to a minimal one (removing any fact would break the proof).
  • Only this is proven: if the facts hold as the stated constraints, then φ is necessarily true (T), necessarily false (F) or undetermined (U).
  • Each candidate’s facts are consistent in both modes (no contradictory claims).
  • The fewest missing proofs is a MaxSAT optimum: fewer proofs cannot make T_M = T.

4 · What it explicitly does NOT prove

  • It does not prove the claims are true or that the interpretation of the quotes is correct – the input is the same as for TREE.
  • It does not prove the selected candidate is suitable; the P3 ranking is a count, not an assessment.
  • A minimal core is one smallest reason; other independent reasons may exist (e.g. two for Tjaša in mode B).
  • It does not assess attitudes or personality, or anything outside the texts.
  • It does not prove the Z3 solver itself is correct (a large C++ codebase); that is why the result is compared with TREE and re-checked from SMT-LIB2.

5 · Assumptions, missing inferences and limitations

Assumptions

  1. The same ad classification, cue lexicon and policy P1–P3 as with TREE.
  2. A stated level is a lower bound; Z3 encodes it directly as L ≥ n, so a lower level naturally yields U.
  3. MaxSAT for missing proofs uses a monotone abstraction of the tree (each atom has its own variable; the tree has only ∧/∨) – exact for this tree.
Selection policy
  • P1 A candidate whose root T_M = F (proven NOT to meet mandatory requirements) is excluded.
  • P2 If any candidate has T_M = T, that candidate is selected; ties are broken by satisfied atoms in T_N, then T_P.
  • P3 If no candidate has T_M = T, TREE selects nobody as suitable. Among non-excluded candidates a PRIORITY candidate for verification is ranked by: (1) number of mandatory items = T, (2) number of mandatory atoms = T, (3) fewer mandatory atoms = F, (4) T_P, (5) T_N.

Limitations
